# MedSecure Frontend

Frontend workspace for the Next.js 14 SaaS UI.

## Folder Usage

- `src/components` reusable UI components
- `src/pages` route-level page modules
- `src/hooks` shared React hooks
- `src/services` API clients and integrations
- `src/context` global state and providers
- `src/utils` helper utilities
- `src/layouts` dashboard and marketing layouts

The actual Next.js app setup will be added in the frontend build step.
